# ElbashaFoodApp 

A food ordering mobile application built with **React Native**, **Expo**, **TypeScript**, and **Supabase**.

The app provides a clean restaurant ordering experience with menu browsing, category-based UI, cart flow, checkout, and backend-ready structure.

---

## Features

- Browse food menu items
- Category-based menu structure
- Product details and item selection
- Cart and checkout flow
- Clean reusable UI components
- Supabase-ready backend structure
- Firebase-ready push notification setup
- Mobile-first user experience

---

## Tech Stack

- React Native
- Expo
- TypeScript
- Supabase
- Firebase
- Git & GitHub
